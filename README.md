# WhatsApp 翻译助手

当前版本 **v1.0.2**。适用于 Chrome / Edge 的 WhatsApp Web 扩展（Manifest V3）。

## 功能
- OpenAI / DeepSeek 翻译，设置页自动检查模型列表，列表变化时更新本机缓存。
- 发送译文、只翻译并替换输入框、发送原文、朗读译文。
- 收到的外语消息翻译为中文，引用消息优先提取当前正文。
- 聊天栏选择目标语言并记住联系人配置。
- 浏览器、ElevenLabs、OpenAI gpt-4o-mini-tts 语音，按语言记忆声音。

## 安装与更新
1. 下载并解压版本安装包，保留在固定目录。
2. 打开 Chrome 的 chrome://extensions/ 或 Edge 的 edge://extensions/，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择含 manifest.json 的目录。
4. 打开 https://web.whatsapp.com/，在扩展设置中填写自己的 API Key。
5. 升级时覆盖原目录所有文件、重新加载扩展并刷新 WhatsApp；不要先卸载，以免丢失设置。

## 使用
在输入框上方选择语言后自动为当前联系人保存，无需在设置页另行保存。点击“只翻译”可先检查译文，再按回车或点击发送确认。语音及其他设置在扩展面板修改后需点击保存。

## 数据与费用
API Key 与默认设置存入浏览器扩展同步存储；联系人配置及模型缓存保存在本机。翻译文本发送给选定的翻译服务商，在线朗读文本发送给对应语音服务商。在线 API 可能产生费用。发布包不包含用户 API Key、聊天记录或联系人配置。在线语音为 AI 合成。

## 已知限制与验证
- 通过模拟回归与语法检查；未完成真实 WhatsApp 登录页面及付费 API 的端到端验证。
- WhatsApp 页面结构变化可能影响按钮、输入框和联系人识别。旧聊天编号不可用时按明确的聊天标题记忆；改名后需重新选择语言，同名联系人建议使用不同备注。无法识别时，语言仍在当前聊天临时生效。
- 最近三代模型按名称中的版本号推断；服务商未返回的历史模型不会补齐，无代际标记的别名保留。
- OpenAI 单次朗读限制为 4096 字符。
